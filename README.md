# CyberSecurity Projects

Repositório central dos meus projetos e laboratórios práticos de Cybersecurity. Cada projeto possui seu próprio repositório, histórico e instruções de execução; esta página reúne os links para facilitar a navegação.

Atualmente estudo Análise e Desenvolvimento de Sistemas e desenvolvo conhecimentos em Python, redes e segurança da informação por meio de projetos educacionais.

## Projetos

### 1. Cybersecurity Log Analyzer

Analisador de logs de autenticação escrito em Python. Lê eventos de login e sinaliza padrões de falhas repetidas que podem merecer investigação.

- [Acessar repositório](https://github.com/DzyRazor/01-cyber-log-analyzer)
- Conceitos: leitura de arquivos, strings, listas, dicionários, funções e análise de eventos.

### 2. Python Port Scanner

Scanner TCP educacional que verifica a resposta de portas em um host informado.

- [Acessar repositório](https://github.com/DzyRazor/02-python-port-scanner)
- Conceitos: endereços IP, portas, TCP, sockets, timeout e tratamento de conexões.

### 3. Network Traffic Analyzer

Analisador de tráfego de rede que usa Scapy para observar informações básicas de pacotes IPv4, TCP e UDP.

- [Acessar repositório](https://github.com/DzyRazor/03-network-traffic-analyzer)
- Conceitos: pacotes, endereços IP, protocolos, portas e captura de tráfego.

## Uso responsável

Estes projetos têm finalidade educacional. Execute ferramentas de rede somente em equipamentos e redes próprios ou com autorização explícita. Os resultados são indicadores para estudo e investigação, não prova isolada de uma atividade maliciosa.

## Evolução

Os projetos fazem parte da minha trilha prática de estudos e serão revisados e aprimorados conforme aprofundo os conceitos e reconstruo cada implementação passo a passo.
